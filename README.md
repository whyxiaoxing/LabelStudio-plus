# 这是label-studio 的改进版本
---
> [!NOTE]
> 至少保证你的CPU有8个线程<br>
> 至少保证该项目实在固态硬盘设备中运行<br>
> 至少保证你的设备是千兆网卡<br>
> 不能保证上面的要求，你的效果可能会打折扣<br>
---
## 改进了什么？
1. 解锁了导出部分限制
2. 支持多线程
3. 前端改进了笔刷 ，具有记忆功能
4. 优化了部署
5. 解决了路径问题 尽可能避免使用 `os.path` 去拼接路径
6. 将环境变量落地到cfg文件，避免每次都要加入环境变量

## ML backend 有什么
ml backend 中存在一套CPU/GPU的 YOLO推理模板
---
你需要做什么
1. 随便下载一个文件夹下的内容 你可以直接获取到 较为优秀的 AI coding代码 几乎是我目前能想到的最快推理办法

> 为什么我会这么做 
> AI 遵从我的编码规范与思路下， 我将整个过程压缩并行， 使用多线程结构将任务拆分细节化 ， 在CPU推理中 我会筛选有效数据后才传递下一个线程，避免传递全部数据 这节约内存传递也减少开发 

> 不可避免的是 AI会写很多的IF 去判断是否为有效值 并且 这些代码未经测试我就放出来了， 庆幸的是 这个思路我已经实地检验两次 逻辑没有问题，就是接口对接很容易出bug ，重点是 mask部分
